# Project Brief

## Nombre del proyecto
Reserva de Salas - Ayuntamiento de Valdemora

## Objetivo general
Mejorar la gestión de reservas de salas en los centros cívicos mediante un sistema centralizado, trazable y consistente.

## Problema actual
- Gestión mediante correos, llamadas y hojas de cálculo.
- Información no unificada.
- Errores de solapamiento.
- Mala aplicación de prioridades.
- Falta de trazabilidad.
- Retrasos en periodos de alta demanda.

## Alcance del proyecto
- Backend API (Node.js + Express)
- Frontend web (React)
- Base de datos relacional
- Sistema de roles
- Gestión de estados
- Registro de incidencias
- Histórico y trazabilidad
- Tests unitarios
