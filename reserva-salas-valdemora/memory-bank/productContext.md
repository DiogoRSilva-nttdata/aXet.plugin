# Product Context

## Tipo de producto
Aplicación web administrativa para la gestión de reservas de salas municipales.

## Usuarios principales
- Personal administrativo
- Responsables municipales
- Ciudadanos y asociaciones
- Monitores de actividades

## Valor del producto
- Centralización de la información.
- Reducción de errores de asignación.
- Aplicación coherente de prioridades.
- Mejora de tiempos de respuesta.
- Mayor transparencia para solicitantes.
- Trazabilidad completa del proceso.

## Características clave
- Registro estructurado de solicitudes.
- Calendario visual de disponibilidad.
- Gestión de estados.
- Sistema de roles.
- Gestión de incidencias.
- Histórico de acciones.
