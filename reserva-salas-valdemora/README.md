# 🚀 Instrucciones para ejecutar el proyecto

## 🔧 Backend (API - Express + PostgreSQL)

-- **cd reserva-salas-valdemora/backend**  
   Entra en la carpeta del backend.

-- **npm install**  
   Instala todas las dependencias necesarias del backend.

-- **npm run dev**  
   Inicia el servidor backend en modo desarrollo (puerto 3001).

---

## 💻 Frontend (Interfaz - React + Vite)

-- **cd reserva-salas-valdemora/frontend**  
   Entra en la carpeta del frontend.

-- **npm install**  
   Instala todas las dependencias del frontend.

-- **npm run dev**  
   Inicia la interfaz en modo desarrollo (normalmente puerto 5173).

---

## ✅ Requisitos previos

-- **Node.js instalado**  
   Necesario para ejecutar backend y frontend.

-- **PostgreSQL en ejecución**  
   La base de datos debe estar activa.

-- **Base de datos creada y configurada en .env**  
   El archivo backend/.env debe contener las credenciales correctas.

---
